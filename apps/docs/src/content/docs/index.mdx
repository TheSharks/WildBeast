## Set up your instance

```bash
git clone https://github.com/TheSharks/WildBeast.git
cd WildBeast
pnpm install
```

Then follow the [getting started guide](/self-hosting/getting-started/) to
configure your bot token, connect PostgreSQL and Redis, apply migrations, and
start the bot.
