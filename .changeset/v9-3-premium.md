Added optional [premium subscriptions](https://wildbeast.guide/development/premium/) through Discord's app monetization. Map your SKUs to tiers with `WILDBEAST_PREMIUM_SKUS`; a subscribed server gets 500 tags instead of 50 and 25 promoted tags instead of 2. Premium is off when the variable is unset.
